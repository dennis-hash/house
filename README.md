# InkredTech website

Static marketing site for inkredtech.com (React 19 + Vite + Tailwind CSS v4).

```bash
npm install
npm run dev      # local dev server
npm run build    # static output in dist/
```

Edit content (services, projects, contact details) in `src/data.ts`.
Deploy by uploading `dist/` to any static host (Netlify, Vercel, Cloudflare Pages, cPanel, Nginx).
